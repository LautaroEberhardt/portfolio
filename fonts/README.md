# Portfolio typography

Chillax by Manushi Parikh / Indian Type Foundry is the portfolio's display font, selected by the owner. The original Chillax-Variable.woff2 was extracted from their Chillax_Complete.zip without modifications. Weight range: 200–700.

The file is hosted locally and preloaded. The hero uses weight 300; titles, navigation, buttons and technology names use the shared --font-brand token. Body copy remains Arial for readability.

License: FFL-Chillax.txt, copied unchanged from the supplied archive. The former Pump Pro Light / Questrial configuration is no longer used. Questrial and its license remain as unused legacy assets.
